# Proyecto-Portal-web-y-carrito-de-compras-Urban-Style

 Descripción
Urban Style es una aplicación web orientada al comercio electrónico, diseñada para ofrecer a los usuarios una experiencia sencilla para consultar productos, añadir artículos al carrito y gestionar su compra.

El proyecto incluye un portal web con una interfaz enfocada en productos de moda y un sistema de carrito de compras que permite gestionar los artículos seleccionados antes de finalizar el proceso de compra.

 Funcionalidades
 Página principal de la tienda.

 Visualización del catálogo de productos.

 Consulta de información de los productos.

 Añadir productos al carrito.

 Cálculo del importe total.

 Interfaz orientada a una tienda de moda.
